LiFR-Seg: Anytime High-Frame-Rate Segmentation via Event-Guided Propagation

Xiaoshan Wu, Xiaoyang Lyu, Yifei Yu, Bo Wang, Zhongrui Wang, Xiaojuan Qi
The University of Hong Kong · Southern University of Science and Technology

ICLR 2026

PaperPDFBibTeX

TL;DREvent-guided, uncertainty-aware feature propagation updates semantic predictions at arbitrary query times without a new RGB frame.

Overview

LiFR-Seg predicts interframe semantic maps from one past RGB frame and observed events. It transports semantic features using event-derived motion and learned confidence, then uses temporal memory to refine them. No future RGB frame is required at inference.
