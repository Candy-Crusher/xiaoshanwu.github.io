# Author names and links

All Publications author names are black, including linked, unlinked, visited,
hovered and keyboard-focused names. Hover/focus adds an underline without
changing color. Xiaoshan Wu stays bold. Project/Paper/Code links retain their
existing colors and presentation.

`author-profile-links.json` supplements the original profile mapping with 18
source-checked links. Personal/faculty websites are preferred. When only an
explicit author-linked GitHub, Scholar or OpenReview profile was verified, its
type is stated in the link's tooltip, rather than calling it a personal homepage.
Every addition records a primary source and identity-disambiguation basis.
Same-name people and guessed GitHub Pages URLs are not used.

The 16 publication bylines and their order are unchanged in this update. The
nine S4NDBOX initials still need a non-anonymous author line or BibTeX: the
available CV only supplies initials, and the manuscript/project page withhold
the author list. This is a missing-source item, not a completed full-name edit.
No initials are replaced with guessed full names or silently removed.

The dedicated publication regression test checks normal/hover/focus author
colors, exact profile destinations and tooltip types in desktop and mobile
browsers, alongside existing font, cover, venue, summary and favicon checks.
